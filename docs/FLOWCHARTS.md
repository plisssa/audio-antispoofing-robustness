# Блок-схемы эксперимента

Файлы:
- `flowcharts.drawio` — обе схемы (две вкладки) для draw.io / diagrams.net: узлы двигаются, стрелки следуют, правится текст/размер/цвет. Это основной редактируемый файл.
- `flowchart_methodology.mmd` / `flowchart_pipeline.mmd` — те же схемы как Mermaid-исходники.

## Как открыть/править .drawio
- Онлайн: https://app.diagrams.net → File → Open From → Device → выбрать `docs/flowcharts.drawio` (без регистрации). Переключение схем — вкладки снизу.
- Приложение: draw.io Desktop (открыть файл).
- В Figma: плагин «diagrams.net» (вставить .drawio), либо в draw.io Export as → SVG и импортировать SVG в Figma (станет слоями).
- Экспорт картинки: в draw.io Export as → SVG/PNG/PDF (любой масштаб) → вставить в курсовую.

## Как получить картинку
- Быстро: открыть https://mermaid.live, вставить содержимое `.mmd` → экспорт SVG/PNG.
- Локально: `npx @mermaid-js/mermaid-cli -i docs/flowchart_methodology.mmd -o methodology.svg`
- В draw.io: Arrange → Insert → Advanced → Mermaid.

## Условные обозначения (ГОСТ 19.701 / ISO 5807)
| Фигура | Смысл | В схеме |
|---|---|---|
| Овал (скруглённый) | начало / конец (терминатор) | серый |
| Параллелограмм | данные (вход/выход) | зелёный |
| Прямоугольник | процесс / действие | синий |
| Ромб | решение, ветвление (да/нет) | янтарный |
| Прямоугольник с двойными боками | подпрограмма (раскрывается отдельно) | фиолетовый |
| Кружок с буквой | соединитель: А — цикл, Р — переход к отчёту | янтарный |

Дополнительные цвета ролей: бирюзовый — искажения (режимы A/B), красный — adversarial и аварийная остановка.

## Правила, которые соблюдены
- Ромб только для решений (ровно один вход, помеченные выходы да/нет); прямоугольник для действий.
- Каждое ребро подписано: на решениях — да/нет; на методологии — что передаётся (домен, порог t*, Δscore).
- Длинные возвраты/переходы — через соединители (А, Р), а не через линии-обёртки.
- Блоки пронумерованы (ГОСТ) — на них можно ссылаться из текста курсовой.
- Цвет кодирует роль блока; есть легенда.

## Что схемы делают явным (ключевые решения дизайна)
1. Одно обучение (reference на ASVspoof2019), нейросети — zero-shot.
2. Факторный цикл: всё повторяется для каждой пары (модель × домен) — соединитель А.
3. Эффект потолка: деградацию мерим на родном домене; на «сломанных» — только сдвиг распределения.
4. Три режима воздействия как единая ось; синтетика ↔ реальные корпуса парно.
5. Adversarial ветвится по дифференцируемости (white-box FGSM/PGD либо только перенос).
6. Пайплайн: fail-fast на обязательных стадиях, optional → skip, resume по .done + partial.csv.
